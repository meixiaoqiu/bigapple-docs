# 建设计划

这里记录大苹果社区从当前方案设计状态走向现实运行的整体建设路径。

## 建设范围

整体建设包括以下方面：

- **制度整理**：将分散的理念、规则和讨论整理为结构化的治理文书和运行制度；
- **成本验证**：建立成本模型，验证共同生活在不同规模下的经济可行性；
- **组织主体**：研究并设立适合社区长期运行的法律组织主体；
- **公司设立**：在适当阶段成立运营实体，承接资产、合同和对外关系；
- **人员形成**：逐步形成首批成员、贡献者和治理参与者；
- **Live OS**：开发并持续完善支撑社区运行的信息系统；
- **仿真验证**：在投入现实资源前，通过仿真提前暴露制度和流程问题；
- **首个园区**：在条件成熟时选址、建设并运行第一个现实共同生活据点。

## 与其他内容的关系

- **Live OS 产品规划**和**Live OS 产品路线图**是整体建设计划中软件专项的组成部分，描述了信息系统的功能设计和开发阶段，不属于社区总体建设计划本身。
- 建设计划描述"准备怎样做"，不等于已经生效的社区制度或治理文书。已生效的制度见[治理文书](../governance-instruments/index.md)。

## 当前状态

大苹果社区当前处于**方案设计、制度整理、软件开发与数字化仿真阶段**。现实社区尚未正式建立。

当前工作集中在规则整理、成本与组织模型研究、Live OS 开发、仿真准备和开放文档建设。各阶段的前置条件和完成标准将在后续版本中逐步明确。

## 尚待编写的内容

以下专项计划将在后续逐步加入：

- 制度整理计划
- 成本验证计划
- 组织主体研究
- 公司设立计划
- 首批成员形成计划
- 仿真验证计划
- 首个园区建设计划

当前总体计划仍在持续整理和修订中。
