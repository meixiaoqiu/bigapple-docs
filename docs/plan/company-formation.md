# 公司设立计划

> **状态：讨论草案**
>
> 本文是大苹果社区总体建设计划中的专项研究文件，当前尚未正式启动公司设立，尚未开展股份认购或收款。本文不构成投资邀请、收益承诺或公司对任何人的承诺。实际方案需经过律师、会计师、税务专业人员及未来正式决策程序审查。

## 为什么需要成立公司

大苹果社区的目标是建立真实的共同生活，这不能只依靠个人、松散成员或软件系统运行。

在现实法律环境中，以下事项需要一个合法设立、能够独立承担权利义务的组织主体：

- 对外签订园区租赁、改造和采购合同；
- 雇佣员工和购买专业服务；
- 持有和管理经营资产；
- 收取房租、餐费及其他经营收入；
- 承担财务核算、纳税和审计责任；
- 为社区提供长期、稳定、可追责的运营主体；
- 对外承担明确的合同责任。

没有合法主体，社区在签约、用工、纳税、资产持有和责任承担方面将面临严重的法律风险，也无法以统一身份对外合作。

成立公司不是项目的最终目的，而是现实建设所需的组织工具。

## 公司不等于社区

大苹果社区、社区治理体系、公司和 Live OS 是四个不同的对象，不能混为一谈：

| 对象 | 主要性质 |
| ---- | -------- |
| 大苹果社区 | 共同生活、共同建设和社区成员关系 |
| 社区治理体系 | 形成和执行社区共同规则 |
| 公司 | 对外经营、签约、持有资产和承担法律责任 |
| Live OS | 支撑成员、任务、资源、治理和审计的软件工具 |

由此产生几个重要区分：

- 成为公司股东不当然等于永久拥有社区成员资格；
- 成为社区成员也不当然等于持有公司股份；
- 社区治理决定不能自动替代公司法定决策；
- 公司股东会、董事会等法定程序也不能自动替代社区治理程序；
- 二者之间的授权和合作关系需要以后通过正式文件明确。

保持这种区分，才能避免公司股东凭借经济权益控制社区生活，也避免社区治理绕过法定程序干预公司运营。

## 拟研究的公司形式

当前重点研究以发起方式设立境内股份有限公司的可行性。

选择该方向主要基于以下考虑：

- 可以容纳多名共同发起人，适合多方共同设立的场景；
- 股份和股东权利较容易标准化，便于明确经济权益和治理权益；
- 更适合区分经济权益、治理权益和创始控制安排；
- 有利于未来形成清晰的股份转让、继承和长期持有规则。

同时需要明确：

- 这只是当前研究方向，尚不是最终法律结论；
- 是否采用股份有限公司，还需与有限责任公司、持股平台等方案比较；
- 涉及类别股、表决权差异和转让限制的设计必须接受专业审查；
- 不能在本页断言某种复杂股份结构已经可以直接实施。

## 公司计划承担的职责

按照现实运营需要，公司可能承担以下职责：

- 园区租赁、建设、维修和运营；
- 住房、食堂、公共设施等服务；
- 任务发布、采购和真实劳务结算；
- 员工用工、社会保险和安全保障；
- 财务、税务、审计和资产管理；
- Live OS 的运营与必要知识产权安排；
- 对外合作、保险和专业服务采购；
- 依法向股东提供信息和处理利润分配。

以下事项暂不应由公司直接决定：

- 社区成员价值判断；
- 社区共同生活的全部规则；
- 成员之间纯私人关系；
- 仅凭公司股权决定社区身份和社区治理权。

## 公司设立前必须解决的问题

以下问题需要在本计划推进过程中逐一研究并形成方案。当前均标注为待研究，不在本页仓促作出结论。

- 采用何种公司形式（股份有限公司、有限责任公司或其他主体）；
- 谁可以成为正式发起人；
- 发起人数及资格条件；
- 注册资本和实际资金需求；
- 每名发起人的出资义务；
- 创始控制权与其他股东保护；
- 是否需要设置不同类别股份；
- 公司与社区治理体系的关系；
- 股东和守约者身份的关系；
- 公司需要取得或使用哪些商标、域名、软件和其他知识产权；
- 股东退出、股份转让、继承和失去社区成员资格时如何处理；
- 公司失败、暂停设立或无法取得园区时如何处理。

## 发起人候选人与正式发起人的区别

### 了解和表达意向

任何人可以：

- 阅读公开计划；
- 理解项目方向；
- 表达未来参与意向；
- 进入候选人联系名单。

但这不代表：

- 已经认购股份；
- 已经承诺出资；
- 已经取得股东身份；
- 公司已经承诺接纳他为发起人。

### 正式发起人

只有完成以下事项后，才可能成为正式发起人：

- 身份和资格核验；
- 充分了解项目风险；
- 阅读并签署正式法律文件；
- 接受公司章程和发起人协议；
- 履行依法确定的出资义务；
- 完成公司设立所需程序。

本页不建立候选人登记页面，不开放报名入口。

## 公开计划与公开融资的边界

在正式法律方案完成前，应当区分可以公开的信息和不应公开提供的事项。

可以公开：

- 项目理念；
- 公司设立研究方向；
- 预计实施步骤；
- 风险和未决问题；
- 候选人形成原则。

在正式法律方案完成前，不应公开提供：

- 收款账户；
- 立即购买股份的按钮；
- 标准化投资套餐；
- 保本承诺；
- 固定收益承诺；
- 强制回购承诺；
- 任何让不特定公众直接汇款并取得投资权益的流程。

这一区分是为了确保项目在具备充分法律准备之前，不因操作不当而触碰证券监管或其他法律风险。

## 股东可能获得什么

股东可能依法取得：

- 公司股份；
- 相应的表决、知情和监督权；
- 公司存在可分配利润并依法作出决议后的分红；
- 股份依法转让产生的价值；
- 公司清算时依法参与剩余财产分配；
- 股东另外为公司提供真实劳动或服务时取得的合理报酬。

同时需要明确：

- 不保证盈利；
- 不保证分红；
- 不保证股份升值；
- 不保证收回投资本金；
- 真实劳动报酬与股份分红属于不同法律关系；
- 社区低成本生活不能简单写成股东固定投资回报。

## 拟定的设立步骤

建议按照以下顺序推进公司设立。具体顺序可能因专业意见和登记要求调整。

1. 完成公司设立研究草案；
2. 委托律师、会计师和税务专业人员审查；
3. 确定公司形式和基本治理结构；
4. 形成发起人候选人规则；
5. 对候选人进行定向沟通和资格核验；
6. 确定正式发起人；
7. 起草公司章程、发起人协议等法律文件；
8. 明确注册资本、出资安排和资金用途；
9. 正式签署文件并依法缴纳出资；
10. 办理公司登记；
11. 建立银行、财务、税务、审计和印章管理制度；
12. 公司成立后再进入园区签约和现实运营准备。

## 进入正式设立阶段的条件

在实际启动签约和收款前，至少需要满足以下条件：

- 公司形式已经确定；
- 法律和税务方案已经经过专业审查；
- 资金预算和用途能够解释；
- 公司与社区的边界形成书面方案；
- 发起人资格和遴选规则已经明确；
- 风险、退出和失败处理已经形成基本规则；
- 正式法律文件已经准备完成；
- 不再仅依靠口头承诺或个人理解。

## 暂停或终止条件

公司设立不是必然推进。出现以下情况可以暂停：

- 法律结构无法满足项目需要；
- 资金需求无法合理核算；
- 发起人无法形成稳定共识；
- 项目控制与股东权益无法合理平衡；
- 首个园区不存在可行方案；
- 专业审查发现重大风险；
- 公开计划与现实能力明显不匹配。

暂停不代表项目失败。可以返回前一阶段继续研究和验证，在条件改善后重新推进。
