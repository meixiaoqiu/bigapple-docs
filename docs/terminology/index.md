# 术语与概念

这里集中解释大苹果社区的重要术语、核心理念及其制度边界。术语页用于帮助读者建立共同语境；具体规则是否已经生效，仍应以正式的[治理文书](../governance-instruments/index.md)为准。

## 社区与理念

- [大苹果社区](./big-apple-community.md)：以降低基本生活成本为首要目标，由成员共同建设、共同治理的现实生活共同体。
- [免费活着](./free-living.md)：共同体为符合条件的成员提供基础住宿和基本食物的最低生活保障理念。

## 身份与关系

- [贡献者](./contributor.md)：注册 Big Apple Live OS 即取得贡献者身份，真实的关注、使用和反馈本身就是贡献。
- [守约者](./covenant-keeper.md)：与社区建立正式、持续成员关系，自愿接受共同规则与成员责任，并持续履行承诺的人。
- [执衡者](./deliberator.md)：自愿承担治理义务的守约者，依照共同之约参与提案、审议、表决和集体裁决。

## 经济与资源

- [贡献积分](./contribution-points.md)：社区用来衡量公共贡献和分配稀缺资源的内部记账单位。
