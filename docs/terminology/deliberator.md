# 执衡者

**英文：Deliberator**

### 定义

**执衡者**，是自愿承担社区治理义务，依照共同之约参与提案、审议、表决和集体裁决，并对履职情况承担责任的守约者。

任何符合条件的守约者，都可以依照公开规则自主申请成为执衡者。取得这一角色通常不需要经过选举、推荐或者资格审核，但申请人必须接受相应的治理义务、履职记录和失职责任。

### 为什么称为"执衡者"

"衡"是衡量事物的尺度，也包含比较、权衡和判断的含义。

社区中的提案往往不能只看某一个人的利益，也不能只考虑眼前是否方便。执衡者需要综合考虑：

- 共同之约与现行规则；
- 提案涉及的事实与证据；
- 不同成员的利益和处境；
- 社区现有资源与执行能力；
- 决定可能产生的长期后果；
- 对后续制度和类似事项的影响。

"执衡"不是掌握凌驾于他人之上的权力，而是执掌一份平等的判断责任。

每名执衡者都拥有自己的一票，但任何单独的执衡者通常都不能代表社区作出决定。社区决定由全体符合条件的执衡者依照表决规则共同形成。

因此：

> 执衡者不是社区的统治者，而是共同承担判断、表决和问责责任的人。

### 执衡者是一种公共职分

执衡者不是比普通守约者更高的成员等级，也不是一种荣誉称号。

守约者申请成为执衡者，意味着他愿意额外承担共同治理工作，包括阅读材料、参与讨论、完成表决、处理争议以及接受履职监督。

这种角色更接近一种公共职分：

- 治理资格不是奖品；
- 表决权不是个人特权；
- 履职不是获取积分的普通任务；
- 治理决定必须面向共同体整体负责；
- 拥有更多决定权，也意味着承担更多义务。

执衡者与其他守约者在人格和基本成员地位上平等。区别只在于执衡者主动承担了额外的治理职责。

### 谁可以成为执衡者

执衡者原则上应当由守约者担任。

成为守约者，意味着一个人已经接受社区的基本目标、共同规则和成员责任。在此基础上，他可以自主决定是否进一步承担治理义务。

一般路径为：

> 贡献者 → 成为守约者 → 自主申请成为执衡者

执衡者资格不应仅根据下列条件授予：

- 财富多少；
- 贡献积分高低；
- 在社区中的资历；
- 与管理者的私人关系；
- 是否经常赞同多数意见；
- 是否拥有某种社会身份或职业地位。

社区治理不应永久被少数资历较深、资源较多或者更接近系统管理者的人垄断。

### 为什么可以自主申请

大苹果不把治理权理解为少数精英经过筛选后才能取得的特殊权力。

只要一名守约者愿意承担公开规定的治理义务，就应当原则上向他开放治理参与渠道。

自主申请制度可以减少以下问题：

- 少数人长期垄断治理；
- 现有治理成员只选择自己认可的人；
- 以能力审查为名排斥不同意见；
- 治理资格逐渐演变为荣誉和特权；
- 普通守约者只能服从，不能承担共同责任。

自主申请并不意味着执衡者可以不受约束。

取得角色容易，是因为治理渠道应当开放；保有角色需要履行义务，是因为共同决定不能由长期缺席或拒绝负责的人掌握。

### 执衡者的治理资格

执衡者可以依照具体治理规则取得相应资格，包括：

- 发起符合条件的提案；
- 查看履职所必需的治理资料；
- 对提案提出意见、修改建议或反对理由；
- 参与正式讨论和审议；
- 对待决事项进行表决；
- 参与争议、申诉和责任事项的集体裁决；
- 对治理程序提出质疑；
- 提议修改不合理的制度和流程；
- 查看公开的表决结果与治理记录。

不同事项可以适用不同的提案条件、参与范围、通过比例和表决期限。执衡者必须按照该事项适用的规则参与，而不能自行改变程序。

### 执衡者的治理义务

治理资格必须与治理义务绑定。

执衡者应当承担的基本义务包括：

- 关注已经进入正式程序的治理事项；
- 在规定期限内阅读必要材料；
- 对要求参与的事项完成表决；
- 不得长期无故缺席；
- 不得在完全不了解事项的情况下敷衍投票；
- 应当如实说明与事项有关的重大利益关系；
- 不得利用治理资格为自己或特定关系人谋取不正当利益；
- 不得伪造、篡改或者隐瞒治理信息；
- 不得干扰其他执衡者独立表达和投票；
- 接受公开规则规定的履职记录与问责。

对于要求全体执衡者参与的提案，每名执衡者都负有完成表决的责任。

参与表决不等于必须赞成，也不等于必须服从多数人的预期。执衡者可以投赞成票、反对票，或者依照规则选择其他有效意见，但不能长期通过缺席逃避判断责任。

### 集体议决与集体裁决

执衡者的工作同时包含议事和裁决性质。

对于一般提案，执衡者需要了解事项、参与讨论并作出判断，由全部有效投票共同形成社区决定。这可以称为**集体议决**。

对于争议、申诉、责任认定或者规则适用问题，执衡者需要判断事实、适用规则并形成结果。这可以称为**集体裁决**。

无论属于议决还是裁决，都应当遵循同样的基本原则：

- 依据公开规则；
- 允许不同意见存在；
- 尊重事实和证据；
- 避免个人利益控制判断；
- 由集体程序而非个人意志产生结果；
- 保留必要的过程和结果记录。

例如，某项提案可以规定所有执衡者都必须参与表决，并在有效票中获得超过半数赞成后通过。

在这种情况下，每名执衡者都作出一份个人判断，最终结果则是这些判断依照既定规则形成的集体裁决。

### 履职为什么不获得奖励

执衡者正常完成提案阅读、讨论和表决，原则上不因此获得额外贡献积分。

原因不是治理工作没有价值，而是执衡者在申请该角色时，已经主动接受这些工作作为角色义务。

如果每次投票都获得奖励，可能产生以下问题：

- 有人为了赚取积分而申请治理角色；
- 治理参与被理解为普通计件任务；
- 投票数量比判断质量更受重视；
- 公共权力与个人收益形成直接交换；
- 人们可能为了获得奖励而制造不必要的治理事项。

因此，大苹果对执衡者采取的基本原则是：

> 正常履职是本分，不额外奖励；拒绝履职或者严重失职，则需要承担责任。

这并不妨碍社区对特别繁重、具有明确成果并超出普通履职范围的工作另行发布任务，但这类任务必须与普通表决义务明确区分。

### 哪些情况可能被扣除贡献积分

执衡者做出不受欢迎的判断，不应受到处罚。

可能导致扣除贡献积分或者其他履职责任的，应当是可识别的失职与违规行为，例如：

- 无正当理由长期不参加必须参与的表决；
- 多次超过期限且不作任何回应；
- 取得治理资格后持续拒绝履行治理义务；
- 伪造投票、讨论或者履职记录；
- 故意隐瞒与待决事项有关的重大利益冲突；
- 利用治理资格为自己或他人谋取不正当利益；
- 泄露依照规则需要暂时保密的治理信息；
- 威胁、收买或者强迫其他执衡者改变意见；
- 严重破坏治理程序；
- 其他已经由公开规则明确列出的失职行为。

扣分标准、认定程序和申诉渠道都应当提前公开，不能由某个管理员临时决定。

### 不得因意见本身受到处罚

执衡者的独立判断必须受到保护。

下列情况本身不能作为处罚理由：

- 投票反对一项最终获得通过的提案；
- 支持一项最终未获通过的提案；
- 经常持少数意见；
- 公开批评提案内容；
- 质疑其他执衡者或者管理者的判断；
- 判断后来被证明存在错误；
- 提出一项不受欢迎但符合程序的提案；
- 拒绝按照私人关系或者群体压力投票。

治理制度可以要求执衡者履行程序义务，却不能要求所有人得出相同结论。

否则，所谓治理就会退化为要求成员确认已经决定好的答案。

因此：

> 问责针对失职、欺骗和程序违规，不针对意见、立场和投票方向。

### 执衡者与守约者

每名执衡者都应当首先是守约者。

守约者身份表示一个人与社区建立了长期成员关系；执衡者角色表示他在此基础上进一步承担了治理职分。

两者关系为：

> 每名执衡者都是守约者，但守约者不一定是执衡者。

守约者没有义务必须申请成为执衡者。

不愿意参与治理，不影响一个人作为守约者生活、贡献和参与其他公共事务。社区不应因为守约者没有申请治理角色，就认为其成员地位较低。

### 执衡者不是其他守约者的代表

执衡者与国家中的议员、人大代表存在一定相似之处，但两者并不完全相同。

执衡者参与公共提案、讨论和表决，也对共同事务作出集体决定；但执衡者原则上不是由某个选区、群体或者其他守约者选举出来的代表。

他不应声称自己天然代表所有未申请成为执衡者的守约者。

每名执衡者只对自己的判断、投票和履职行为负责。社区决定的正当性来自开放的申请渠道、平等的表决权和公开的治理程序，而不是来自某种代表授权。

### 如何退出执衡者角色

执衡者是一种主动承担的职分，不应成为永久身份。

执衡者可以依照规则主动申请退出，但退出前可能需要：

- 完成已经开始且必须参与的事项；
- 处理尚未履行的必要义务；
- 移交需要移交的资料；
- 确认不存在借退出逃避正在进行的问责。

退出执衡者角色后，一个人仍然可以保有守约者身份，也可以继续以其他方式参与社区。

### 如何失去执衡者资格

在下列情况下，一个人可能失去执衡者资格：

- 主动退出；
- 不再具有守约者身份；
- 长期拒绝履行治理义务；
- 严重违反治理规则；
- 经公开程序认定不再适合继续履职；
- 发生规则规定的其他终止情形。

失去执衡者资格不应自动等同于失去守约者身份。

只有当相关行为同时严重违反共同之约或者守约者义务时，才应当另行启动守约者身份处理程序。

### 常见问题

**执衡者是不是社区领导人？**

不是。

执衡者拥有一份平等的提案、审议和表决资格，但不能单独决定社区事务，也不是普通守约者的上级。

**成为执衡者需要选举吗？**

原则上不需要。

符合条件的守约者可以自主申请，但取得角色后必须承担公开规定的治理义务。

**没有治理经验，也能申请吗？**

原则上可以。

社区可以提供规则说明、治理培训、模拟表决或者必要的阅读材料，但不应仅以缺乏经验为由永久排除愿意承担责任的守约者。

**执衡者投错票会被扣分吗？**

不会因为投票结果或者意见方向被扣分。

扣分针对的是无故缺席、拒绝履职、欺骗、隐瞒利益冲突或者严重破坏程序等行为。

**为什么参与治理没有积分奖励？**

因为正常参与治理是执衡者主动接受的职分义务，不是按次数结算的普通任务。

做得好属于履行本分，严重失职则需要承担责任。

**所有提案都要求全体执衡者参加吗？**

由具体治理规则决定。

重要事项可以要求全体执衡者参与，其他事项也可以规定不同的最低参与人数、表决期限和通过比例。

**执衡者可以不投票吗？**

在规则允许弃权时，可以提交有效弃权意见；但不能把长期缺席或者拒绝回应当作弃权。

弃权本身也是一种正式治理行为，应当依照规则记录。

**管理员拥有后台最高权限，是否自动成为执衡者？**

不会。

技术权限和治理资格相互独立。管理员要参与治理，仍然需要先具备守约者身份，并自主申请成为执衡者。

**执衡者是否代表没有申请治理角色的守约者？**

不天然代表。

执衡者依据自己的判断参与治理。未申请治理角色的守约者仍可以通过公开意见、反馈渠道以及其他制度参与共同事务，但不会因此自动把自己的意见授权给某一名执衡者。

### 相关概念

- **贡献者**：注册 Live OS 并以关注、使用、表达或其他方式为大苹果带来真实价值的人。
- **守约者**：完成正式立约并承担长期成员承诺的贡献者。
- **共同之约**：守约者和执衡者履行成员及治理责任时共同遵循的基本约定。
- **提案**：依照规则提交社区讨论和决定的正式事项。
- **审议**：了解、讨论并权衡提案内容及其影响的过程。
- **表决**：执衡者依照规则表达正式判断的治理行为。
- **集体议决**：多名执衡者通过审议和表决形成社区决定的过程。
- **集体裁决**：执衡者依照事实、规则和程序共同判断争议或待决事项的过程。
- **贡献积分**：记录部分有效贡献，并可用于处理部分责任和资源关系的制度工具。
- **管理员**：受托维护 Live OS、后台系统和数据，但不天然拥有治理资格的技术角色。
